\chapter*{Introduction}
\addcontentsline{toc}{chapter}{Introduction}
Enterprise Architecture (EA) provides a high-level view of an enterprise's business and IT systems and their interrelationships. It can be decomposed to \emph{standards} which allow analysis of the current state of an enterprise and the planning of its evolution, and \emph{models} consists of description of different elements organized in layers (Business, Application, Technology\ldots) \parencite{Gong2019}.

EA has been shown to reduce IT costs, improve communication, and strengthen business--IT alignment \parencite{Gong2019}. Several EA frameworks exist, including the Federal Enterprise Architecture Framework (FEAF), developed for and used by the U.S. federal government, and The Open Group Architecture Framework (TOGAF), widely adopted by organizations.

ArchiMate is the Open Group modeling language used to create EA models. However, to fully exploit these models and automate their analysis via complex queries, a transition to Knowledge Graphs (KG) is being adopted.
Tools like the EAKG Toolkit \parencite{glaser2022toolkit} allow ArchiMate models to be transformed into a KG based on the Property Graph model (supported by the Neo4j DBMS). Another KG standard, originating from the Semantic Web, is the RDF \parencite{w3c-rdf} graph model (supported by other DBMSs such as GraphDB).

The objective of this project is to:

\begin{enumerate}
    \item Provide an algorithm allowing the translation of an ArchiMate model to a RDF knowledge graph. ArchiMate models are provided as input with Archimate Exchange Format\parentcite{archimateExc}. The algorithm, inspired by prior work \parencite{glaser2022model}, must provide the RDF representation of these models. The user will thus be able to import the resulting RDF KG to a DBMS of their choice (GraphDB in our case).
    \item Propose queries to exploit and analyze ArchiMate models through the KG. The queries will be formulated in SPARQL, the standard language for querying the RDF model, similar to SQL for querying a relational model.
    \item The use of an LLM to allow querying the obtained KG in natural language---English---(translating the natural language query into the SPARQL) to answer user questions.
\end{enumerate}
